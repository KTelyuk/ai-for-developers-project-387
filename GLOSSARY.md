# Календарь звонков

Сервис записи на звонок: владелец публикует типы встреч, гость бронирует свободное время без регистрации.

## Участники

**Владелец**:
Единственный хозяин календаря, заданный заранее; публикует типы встреч и видит все записи.
_Avoid_: админ, хозяин, пользователь

**Гость**:
Человек, который записывается на звонок без регистрации, указывая имя, email и, по желанию, предмет разговора.
_Avoid_: клиент, посетитель, пользователь

## Встречи

**Тип встречи**:
Шаблон встречи владельца с названием, описанием и длительностью.
_Avoid_: услуга, событие, мероприятие

**Запись**:
Созданная бронь гостя на конкретное время по одному типу встречи; гость управляет ею по своей ссылке.
_Avoid_: бронь, встреча (в значении брони), заказ

**Предмет разговора**:
Необязательный короткий текст гостя о том, что он хочет обсудить; принадлежит записи.
_Avoid_: тема встречи (занято: тип встречи), заметка, комментарий

**Бронирование**:
Процесс, в котором гость выбирает тип встречи, день и время и создаёт запись.
_Avoid_: запись (в значении процесса)

## Страницы гостя

**Страница бронирования**:
Страница, где гость проходит бронирование.
_Avoid_: страница записи (в значении бронирования)

**Страница записи**:
Страница одной записи, которую гость открывает по своей ссылке и где может её изменить или отменить.
_Avoid_: страница брони
